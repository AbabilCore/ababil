# Ababil - CLI Portfolio

[![npm version](https://img.shields.io/npm/v/ababil.svg)](https://www.npmjs.com/package/ababil)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A beautiful CLI portfolio showcasing work, skills, and projects in the terminal.

## Installation

```bash
# Install globally
npm install -g ababil

# Or run directly
npx ababil
```

## Development

```bash
# Install dependencies
npm install

# Run in development mode
npm run dev

# Build
npm run build

# Test locally
npm start
```

## Customization

Edit `src/data/index.ts` with your information, then rebuild.
